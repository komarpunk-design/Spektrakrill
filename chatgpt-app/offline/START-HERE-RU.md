# Spektrafilm прямо в чате: экспериментальный автономный пакет

Этот архив предназначен для попытки запуска через **«Анализ данных» ChatGPT**, без VPS, OAuth, API-ключа и подключения MCP. Это отдельный способ использования того же движка.

**Работа в настоящем ChatGPT пока не подтверждена.** Проверка в обычном Linux не гарантирует совместимость с его временной средой. Нужны доступный инструмент анализа данных, Linux x86-64, разрешённый запуск локальных программ, достаточно RAM/времени и места. При запрете запуска ограничения не обходятся. Постоянная установка плагина в аккаунт здесь не выполняется.

## Как попробовать

1. Откройте чат с доступным анализом данных.
2. Загрузите архив движка и камерный RAW. Если ChatGPT не принимает расширение RAW, положите **один снимок** в отдельный ZIP.
3. Скопируйте запрос из `CHATGPT-PROMPT-RU.md`.
4. При успешном выполнении ChatGPT сможет показать JPEG и дать ссылки на JPEG, 16-битные PNG и TIFF.

После окончания/сброса временной сессии пакет может потребоваться загрузить снова. Наличие архива в Project/Knowledge не гарантирует, что он автоматически доступен исполняющему инструменту; это зависит от возможностей аккаунта и текущей сессии.

## Что выполняется

Настоящий LibRaw с полной демозаикой → линейный ProPhoto → Arctic → плёнка, RMS, Layered Transport, DIR → Noritsu без бумаги → sRGB. Для BW используется Ilford HP5 с цифровым выводом. Режимы:

- `natural`: Portra 400 + Noritsu;
- `warm`: Kodak Gold 200 + Noritsu;
- `bw`: Ilford HP5 + цифровой скан.

Расчёт и PNG/TIFF-экспорт взяты из Android-проекта. JPEG кодирует тот же закреплённый libjpeg-turbo. Генерация изображения не используется. Неподдержанный RAW возвращает ошибку, без подмены встроенным JPEG.

По умолчанию результат ограничен **1536 пикселями по длинной стороне**, чтобы снизить нагрузку временной среды. Это уменьшенный выход, а не полноразмерный RAW-экспорт. `--size 3072` запрашивает больший размер; `--size 0` — исходное разрешение, если хватает ресурсов. Тяжёлые RAW могут не поместиться даже при небольшом выходе: демозаика читает исходный сенсор.

## Команда

```bash
python /path/to/spektrafilm-offline/run.py /path/to/photo.NEF \
  --output /path/to/new-empty-result --look natural --size 1536
```

Нужен Python 3.9+; используются только его стандартные модули. Скачивание библиотек не выполняется. Бинарники Linux x86-64 полностью статические; профильные данные уже находятся в архиве. `--verify-only` проверяет SHA-256 всех включённых файлов.

Выходная папка должна быть новой или пустой. Исходник не изменяется. Временные RAW и f32 удаляются, готовые изображения получают собственный SHA-256 и `receipt.json`. Временная среда ChatGPT и этот архив не являются долговременным хранилищем — скачайте результат.

## Исходники и лицензии

Полный коммит исходников указан в `manifest.json`. Приложение/адаптер: GPLv3; исходные уведомления и лицензии LibRaw, ICC, libjpeg-turbo и статических runtimes сохранены. Движок C++, декодер и нативные PNG/TIFF-writers собираются из этого репозитория; архив не содержит оригиналов тестовых фотографий, учётных данных или серверных токенов.

## Сборка из исходников

На Linux x86-64 нужны CMake 3.22+, g++, binutils, patch, Git и zlib development files. Из корня репозитория:

```bash
cmake -S chatgpt-app/native -B chatgpt-app/build-offline \
  -DCMAKE_BUILD_TYPE=Release -DSPK_CHAT_STATIC=ON
cmake --build chatgpt-app/build-offline \
  --target spektrafilm-develop spektrafilm-export --parallel 4
python3 chatgpt-app/offline/build-pack.py /path/to/new-package.zip
```

Для публикуемого пакета дерево Git должно быть чистым: manifest указывает точный коммит. Сборка проверяет отсутствие `INTERP`/`NEEDED` в ELF, полноту LFS-материалов и CRC ZIP. Для частной проверки незафиксированных изменений есть `--allow-dirty`; такой пакет не является выпуском.

Проверка launcher:

```bash
python3 -m unittest discover -s chatgpt-app/offline -p test_launcher.py -v
```

Пакет испытан в изолированном Linux с Python без numpy/Pillow/tifffile, сеть отключена, пользователь непривилегированный, RAM 1 GiB, CPU 2. Проверены настоящие NEF и 26-МП RAF с выходом 1536 по длинной стороне. Это не реальная сессия ChatGPT и не подтверждение доступности нативного исполнения в аккаунте пользователя.
