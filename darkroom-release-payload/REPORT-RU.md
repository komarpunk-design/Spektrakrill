# Darkroom Mobile 0.2.1: проверка функций

27 ноября 2026 года. Основа: `togekk39/darktable-android`,
`ae4139bdf18a5c39f71c24f1fb3eab320c139cc9`.

Основной тракт импорта, обработки, истории и экспорта работает на проверенных
файлах. Полного соответствия настольному darktable нет. Ни Linux-проверка
движка, ни Robolectric не заменяют установку APK на Android: телефон и эмулятор
в этой среде не были доступны.

## Исправлено после проверки

1. Перетаскивание фотографии могло восприниматься как выбор точки маски/тона,
   а два пальца — перемещать маску. Общий обработчик теперь отклоняет движение
   сверх системного touch slop, несколько пальцев и точки вне изображения.
   Три воспроизводивших ошибку проверки сначала упали; после исправления все
   шесть проверок жестов прошли, включая обычный тап и небольшое дрожание пальца.
2. Статус коррекции объектива оставался английским в русском интерфейсе.
   Подключены существующие русские ресурсы; добавлена проверка.
3. Поиск профиля объектива не завершал UI-проверку внутри старого диалога.
   Выбор перенесён в поисковую нижнюю панель по образцу каталога инструментов.
   Тот же сценарий выбора и фильтрации теперь проходит. Зависание на настоящем
   телефоне не воспроизводилось: исправлялся обнаруженный host-сценарий.

Проверка параметрических масок также обновлена: перед проверкой порогов она
открывает подписанную группу смешивания, свёрнутую в новом UI. Параметры не удалены.

## Результаты наборов

- 289 Android/JVM-проверок в Debug и отдельно 289 в Release: без ошибок/пропусков.
  Из них 211 входят в обычный source set; ещё 78 — существующие device UI-тесты,
  исполненные дополнительным host-harness под Robolectric SDK 35. Они не были
  запущены как instrumentation на устройстве. Harness и JUnit XML включены
  в отдельный архив доказательств проверки.
- 27 native CTest-сценариев: 26 прошли в первом запуске; оставшийся упал из-за
  попытки создать hardlink между разными bind-mount. После переноса неизменённой
  PNG-фикстуры на тот же том он прошёл за 243 секунды. Код алгоритмов и проверок
  не менялся ради прохождения. Начальный и повторный журналы сохранены отдельно.
- Три JNI-сценария с настоящим скомпилированным Kotlin `NativeCore.class`:
  JPEG, NEF, RAF — пройдены. JNI-мост и движок собраны для Linux из исходников
  этой ревизии; ARM64-библиотеки в APK оставлены оригинальными.
- Release APK, APK инструментальных тестов и Android Lint собраны/выполнены:
  Lint — 0 ошибок, 30 предупреждений, 3 информационных замечания.
- Для упаковки используются побайтово исходные 115 библиотек runtime и
  830 файлов данных. Проверены подпись APK, ZIP CRC, 16-КБ ZIP-выравнивание
  и LOAD-выравнивание всех 116 упакованных native-библиотек.

В исходном проекте не включён дополнительный host source set. Чтобы повторить
289 проверок, распакуйте архив доказательств и подключите `host-ui-suite` через
предоставленный `host-ui.init.gradle` (путь задаёт `DARKROOM_AUDIT_DIR`):

```sh
cd android
DARKROOM_AUDIT_DIR=/absolute/path/to/audit ./gradlew \
  -I /absolute/path/to/audit/host-ui.init.gradle \
  :app:testDevDebugUnitTest :app:testDevReleaseUnitTest \
  :app:assembleDevRelease :app:lintDevRelease \
  -PdarktableRuntimeStage=/absolute/path/to/runtime
```

## Подтверждённые ограничения

Предпросмотр и экспорт не идентичны. При сопоставлении предпросмотра с TIFF
того же размера и sRGB средняя абсолютная разница каналов по шкале 0–255 была
2,055 для NEF и 0,472 для RAF; 95-й процентиль — 9,093 и 1,409. Локальные
максимумы — 103,016 и 48,362. Это не измерение Delta E и не проверка цветовой
точности монитора. В исходном движке отличаются режимы качества и цветового
назначения preview/export; алгоритмы ради маскировки разницы не менялись.

При повторной инициализации Linux runtime зарегистрированы GLib-GObject
critical-сообщения о повторной регистрации `DarktableSignals`. Тесты открытия,
закрытия и пикселей завершились успешно; отсутствие проблем в долгой Android-
сессии этим не доказано. Предупреждения сохранены в полном журнале native-теста.

Из сборки исключены OpenCL/GPU и AI; HEIF/HEIC/HIF, AVIF, rendered JPEG XL,
OpenEXR, WebP и JPEG2000 не включены. XCF экспортируется, но не импортируется.
Не обещается поддержка любого файла с расширением RAW.

Нет постоянных проектов с историей после уничтожения процесса. Cancel завершает
сессию, что явно объясняется подтверждением. Внешний Android share-intent
открывает новую сессию. Полный настольный каталог пресетов/стилей, некоторые
автопикеры, свободное рисование масок и связанные Liquify-workflow не завершены
в исходном порте. См. [CONTROL_PARITY.md](../mobile/CONTROL_PARITY.md) и
[параметры сборки](../mobile/dependencies/build-android-engine.sh).

Скорость, память, длительные сессии и системные диалоги на реальном Android
остаются непроверенными. Этот отчёт не обозначает их как пройденные.
