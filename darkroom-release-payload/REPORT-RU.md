# Darkroom Mobile 0.2.0: что сделано и проверено

26 ноября 2026 года. Отдельная локальная ветка `feat/mobile-workspace` на основе
`togekk39/darktable-android`, ревизия `ae4139bdf18a5c39f71c24f1fb3eab320c139cc9`.
Spektrafilm не изменён. GitHub-форк создать не удалось: API ответил
`403 Resource not accessible by integration`. Изменения подготовлены к ревью
в индексе Git, без коммитов и отправки в чужой репозиторий.

## Интерфейс

Фото находится над панелью инструментов, а в альбомной ориентации — слева от неё.
Размер панелей меняется перетаскиванием границы. Есть развёрнутый просмотр,
масштабирование щипком, перемещение увеличенного фото и возврат к вписанному виду.
При работе с координатами масок/тона масштаб предпросмотра сбрасывается.

Сверху: открыть фото, отменить, повторить, экспортировать. Снизу: свет и цвет,
детали/ретушь, геометрия/эффекты, настройки приложения. Выбор названия инструмента
открывает каталог с поиском; кнопка поиска ищет также параметры во всех разделах.
Выбор выключенного инструмента не включает его. Смешивание и маски находятся
в подписанных раскрываемых группах внутри соответствующего инструмента.
Точный ввод, диапазоны и существующие специализированные редакторы сохранены.

372 строки оболочки переведены на русский. Названия и параметры движка читаются
из его оригинального русского каталога. Есть светлая, графитовая и OLED-темы.
Настройки приложения открываются на всю рабочую область.

## Исправленные проблемы и ограничения

| Наблюдение | Результат |
| --- | --- |
| В сборке по умолчанию отключался настоящий движок | Обычная сборка требует полный runtime; отключённый движок доступен только через явный флаг разработчика |
| Не было Gradle Wrapper JAR | Включён официальный JAR из проверенного Gradle 8.14.4; закреплён SHA-256 дистрибутива |
| Числовой черновик терялся при смене инструмента | Исправлено и проверено вводом точного значения и вызовом исходного адреса параметра |
| Фиксированные половины экрана | Регулируемый размер и отдельная альбомная компоновка |
| Короткий список на маленьком экране | Полноэкранный каталог с поиском и прокруткой |
| Настройки занимали половину экрана | Полноразмерная страница настроек |
| Не было увеличения предпросмотра | Масштабирование/панорамирование и сброс; пиксели экспорта не меняются |
| При смене языка AAB мог не содержать нужные ресурсы | Языковые сплиты отключены; языки включаются в пакет |
| Совпадение идентификатора с приложением автора | Новый ID `design.komarpunk.darkroom.dev`, отдельная установка |
| Отмена операции уничтожала сессию | Добавлено подтверждение последствий; сам унаследованный Cancel по-прежнему завершает сессию |
| Открытие другого фото теряло текущую обработку | Для кнопки открытия добавлено подтверждение; системный выбор файла можно отменить без закрытия фото |
| About показывал неверную ревизию darktable | Исправлено по исходному upstream-lock |

## Выполненные проверки

- 204 Android/JVM-теста в Debug: без ошибок и пропусков.
- 204 Android/JVM-теста в Release: без ошибок и пропусков.
- Включены реальные host-запуски Compose/Robolectric: навигация, сохранение ввода,
  точный вызов параметра, отключённые экземпляры, каталог, полноэкранный просмотр,
  изменение панелей, зум, русский экран 320 dp и альбомная компоновка.
- 39 Python-тестов staging/verifier: пройдены.
- 4 C-теста мобильного адаптера: пройдены; это не полный RAW-процессор.
- Release APK и отдельный APK инструментальных тестов собраны.
- Android Lint: 0 ошибок, 30 предупреждений и 3 информационных замечания.
  Остались в основном старый target SDK, рекомендации обновить зависимости,
  составные intent-фильтры, стилистические замечания и неиспользуемые ресурсы.
- Штатный gradlew запускается и проверяет закреплённый дистрибутив.
- Сборка без runtime отклоняется с инструкцией вместо выпуска неработающего редактора.
- Оригинальный APK проверен по опубликованному SHA-256.
- 115 библиотек движка/runtime и 830 файлов данных в новом APK побайтово совпадают
  с оригинальным APK. Математические алгоритмы обработки не переписывались.
- Все 116 упакованных native-библиотек имеют LOAD-выравнивание не меньше 16 КБ.
  Подпись APK v2 и zipalign проверены. ZIP CRC всего APK и исходников проверены.
- YAML изменённых GitHub workflow-файлов разбирается. В GitHub эти задания не запускались.

## Что не проверено

Телефон или эмулятор не были подключены. Наш APK не запускался на настоящем Android.
Декодирование реальных RAW, влияние каждого параметра на пиксели, полный цикл
экспорта, OEM-провайдеры файлов, клавиатура и восстановление после уничтожения
процесса на устройстве, скорость, расход памяти и цветовое соответствие
предпросмотра экспорту в этом форке не проверены. Побайтовая идентичность движка
не заменяет эти проверки.

Два дополнительных C-набора (module-layout и sidecar) не удалось сконфигурировать:
в среде отсутствуют development-файлы glib-2.0. Инструментальные тесты скомпилированы,
но не выполнялись на устройстве. Снимки UI используют тестовое JPEG-изображение;
это не доказательство RAW-рендеринга движком.

Наследуются ограничения Android-порта: сессионная обработка без постоянного каталога
проектов, отдельные неподдержанные настольные пикеры/пресеты, неполные свободные
маски и связанные деформации, необязательные кодеки. Внешнее Android-поделиться
открывает новую сессию. Ни одна из существовавших ручных регулировок не удалялась,
но полного соответствия настольному darktable здесь не заявляется.

APK подписан ключом разработки, ARM64, Android 8.0/API 26 и выше.
Исходники поставляются отдельным ZIP; журнал и машинный отчёт — рядом с этим файлом.
