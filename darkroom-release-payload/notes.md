Android 8.0+, ARM64. Экспериментальная версия 0.4.0, обновление Darkroom Mobile 0.3.x с сохранением applicationId и подписи.

Добавлены каталог с импортом нескольких фото, поиском/отбором/сортировкой и множественным выбором; оценки, отклонение, пять цветовых меток и иерархические теги через native XMP; последовательная постоянная очередь экспорта с фиксацией обработки каждого кадра, остановкой, продолжением и повтором. Записанный SAF-файл проверяется повторным чтением SHA-256. Меню ⋮ открывает каталог, метаданные и очередь. Прежние стили, маски, история и инструменты сохранены.

Полного соответствия настольному darktable пока нет. Очередь не является фоновой службой; после завершения процесса потребуется продолжение/повтор. Движок 5.8 dev пишет v7-маски, несовместимые со стабильным desktop 5.6.2. Подробные ограничения и неперенесённые области перечислены в REPORT-RU.md и qualification.json.

Проверки: по 330 JVM/Compose-тестов в Debug и Release, 39 Python-тестов, реальные native JPEG/NEF/26-МП RAF с проверкой XMP, больших списков тегов и независимости batch от открытого редактора. Проверки native выполнялись на Linux, а не в APK на Android. Физическое устройство, Android SAF/IME и производительность не проверены.

Скачивайте **Darkroom-Mobile-v0.4.0-arm64.apk**. Прилагаются соответствующие Android-исходники, patch, контрольные суммы и материалы проверки. Автоматические GitHub Source code archives относятся к репозиторию доставки Spektrakrill; Android-исходники — в отдельном приложенном source.zip. Основная ветка и релизы Spektrafilm не заменяются.
