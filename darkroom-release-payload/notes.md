Отдельная экспериментальная Android-сборка Darkroom Mobile 0.2.0 для скачивания с телефона.

APK: ARM64, Android 8.0/API 26 и выше, 37 600 747 байт. Устанавливается отдельно от приложения автора: design.komarpunk.darkroom.dev.

Переработаны рабочая область, каталог инструментов, поиск, масштабирование, альбомная компоновка и русский интерфейс. Оригинальный движок darktable и его runtime сохранены побайтово из проверенного APK togekk39/darktable-android, исходная ревизия ae4139bdf18a5c39f71c24f1fb3eab320c139cc9.

204 Android/JVM-теста прошли отдельно в Debug и Release, 39 Python-проверок и 4 C-теста адаптера также пройдены. Подпись APK и целостность архива проверены. На физическом Android/эмуляторе RAW, экспорт и скорость пока не проверены.

Соответствующие исходники UI-форка находятся в приложенном Darkroom-Mobile-v0.2.0-source.zip, изменения — в .patch. Автоматический GitHub Source code archive этого репозитория не является исходниками Darkroom. Подробности проверки приложены в REPORT-RU.md и qualification.json.

Этот релиз использует существующий репозиторий только как место скачивания. Код и существующие релизы Spektrafilm не изменяются. Отдельный GitHub-форк Darkroom ещё не создан: интеграция не разрешила создание форка.
