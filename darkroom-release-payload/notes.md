Darkroom Mobile 0.3.0 — экспериментальная Android-сборка с рабочими сценариями настольного darktable. ARM64, Android 8.0/API 26+, design.komarpunk.darkroom.dev, versionCode 4. Тот же ключ разработки, что у 0.2.1.

Добавлено:
- Постоянные фото-проекты с оригиналами, native XMP, миниатюрами и импортированными файлами.
- Именованные снимки обработки, восстановление с резервной копией и переход по сессионной Undo/Redo истории.
- Настоящий каталог .dtstyle: импорт, создание, применение append/replace и экспорт через оригинальные API darktable.
- Все 534 штатных стиля: 24 примера и 510 стилей камер; файлы побайтово совпадают с официальным desktop 5.6.2. Фильтры Мои / Примеры / Камеры / Все, поиск и оригинальная локализация.
- Закреплённое сравнение и RGB8-гистограмма предпросмотра с log/linear.
Все новые действия находятся в меню ⋮ верхней панели.

Проверка: по 312 host Android/JVM-тестов в Debug и Release, 39 Python-тестов runtime; 24 native-фазы XMP/стилей на JPEG, NEF и 26-МП RAF; 3 сценария согласованности экспорта и 5 применений встроенных стилей. В проверенных одинаковых состояниях сохранение/восстановление и экспорт до/после передачи контекста дали точные пиксели. Lint: 0 ошибок, 32 предупреждения, 3 замечания. Подпись, ZIP CRC и 16-КБ выравнивание проверены.

Важная граница совместимости: оригинальный движок порта — development 5.8. Реально запущенный официальный desktop CLI 5.6.2 открыл наши XMP, но пропустил v7-маски: он читает v6. Это не объявляется успешной совместимостью. Приложение сохраняет полный родной формат и предупреждает перед экспортом XMP/новых blend-v15 стилей. Непроверенного обратного переписывателя нет. Готовые фотографии доступны в обычных PNG/TIFF/JPEG.

Полного равенства с desktop пока нет: остаются части Lighttable/коллекций, пакетный экспорт, общий браузер модульных пресетов, copy/delete/reorder экземпляров, свободные маски, связанные Liquify и некоторые автопикеры/scopes. GPU/AI и дополнительные кодеки отключены в исходном Android runtime. Preview/export всё ещё могут различаться. На физическом Android/эмуляторе APK не запускался; скорость и память телефона не измерялись.
