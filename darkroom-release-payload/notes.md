Исправленная экспериментальная сборка Darkroom Mobile 0.2.1, ARM64, Android 8.0/API 26+.

Исправлены ложные нажатия по фотографии при перетаскивании и мультитаче. Поиск профиля объектива перенесён в нижнюю панель; статус объектива переведён на русский.

Проверка: по 289 host Android/JVM-тестов в Debug и Release, 27 native CTest-сценариев с повтором одного теста после исправления размещения фикстуры. Реальные NEF и 26-МП RAF обработаны через оригинальный JNI-мост на Linux: экспозиция меняет пиксели, Undo/Redo восстанавливают их точно. Получены полноразмерные PNG16; на RGB-файле созданы все 7 объявленных экспортных форматов. Lint: 0 ошибок, 30 предупреждений, 3 замечания.

На Android-устройстве/эмуляторе APK не запускался. Проверки Linux и Robolectric не заменяют испытание телефона. Предпросмотр и экспорт имеют измеренные различия. GPU/AI и часть кодеков отключены; постоянных проектов и полного настольного набора сценариев нет. Подробная матрица, исправления и ограничения — в REPORT-RU.md; сырые журналы, JUnit XML и host-harness — в audit-evidence.zip.

Движок в APK побайтово сохранён из исходной ревизии ae4139b togekk39/darktable-android: 115 runtime-библиотек, 830 файлов данных. Подпись, ZIP CRC и 16-КБ выравнивание проверены. Приложение использует ID design.komarpunk.darkroom.dev, код версии 3 и тот же ключ разработки, что 0.2.0.

Соответствующие исходники находятся в Darkroom-Mobile-v0.2.1-source.zip, изменения от исходной ревизии — в .patch. Автоматические Source code archives GitHub для этого репозитория не являются исходниками Darkroom. Spektrakrill используется только для доставки отдельного APK и отчёта; код Spektrafilm и существующие релизы не заменяются.
