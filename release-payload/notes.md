Ускорение существующего C++/Vulkan-движка без удаления функций и уменьшения разрешения.

- Layered Transport: корректное распределение тяжёлых свёрток между CPU-потоками.
- Заводской Noritsu: параллельные независимые строки, с сохранением исходных округлений и таблиц.
- Lab-предпросмотр: совместимые индивидуальные GPU-стадии больше не блокируются одним наличием экспериментальных настроек.
- Виртуальные сканеры Nikon/Noritsu и другие приёмники: спектральное считывание через Vulkan с самопроверкой и точным CPU fallback.
- Кеши плёнки и печати разделены для GPU и точного CPU-расчёта.

Проверки: 1529 тестов приложения + 32 RAW, исходный Noritsu oracle, 36 проверок приёмников с реально выполненным Vulkan-проходом, 8 полных цепочек Arctic/Layered/Langmuir/RMS/Nikon/Noritsu, изоляция кешей, 224 CPU preview/export сравнения, исходные goldens. Release ARM64 APK, подпись совместима с предыдущей версией.

Vulkan проверен на программном Mesa Lavapipe, физический Android/GPU недоступен. Ускоренный GPU-результат проверяется с численным допуском; при отказе проверки используется CPU. Замеры отдельных CPU-операторов в облаке показывают ускорение примерно 1.7–2.4 раза при 1→4 потоках; это не замер всего приложения на телефоне.
