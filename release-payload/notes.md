Камерные RAW: исправлено определение формата и добавлена причина отказа декодера.

- Камерные расширения NEF/CR2/CR3/ARW/RAF и другие теперь имеют приоритет над ошибочным JPEG MIME файлового провайдера. Исправление используется редактором, библиотекой и пакетным экспортом.
- Убрана общая ложная надпись про DNG для любого RAW. Кнопка «Причина» показывает фактический статус и исходную строку LibRaw.
- Системный запасной предпросмотр больше не закрепляется на диске как успешное нативное RAW-декодирование. При новом открытии повторяется попытка LibRaw.
- Каталог пресетов 9.59, текущий UI и порядок инструментов сохранены. Алгоритмы обработки и ограничения памяти не ослаблены; экспорт не подменяет сенсорные RAW-данные встроенным превью.

Проверка: 1419 app unit/Robolectric тестов; native raw-precision contract; 16 прогонов четырёх открытых RAW (Canon EOS 5D Mark II CR2, Nikon D700 NEF, Sony ILCE-7M3 ARW, Fujifilm X-T2 RAF), half/full processing, fd/buffer с одинаковыми RGB. В host-проверках задавался бюджет 1 ГиБ, результат ограничивался 1024 px. Это не тест на физическом телефоне и не гарантия достаточной памяти для любого файла.

**Конкретный RAW пользователя не получен: его исходный сбой пока не воспроизведён и не объявляется исправленным.** Для дальнейшего исправления нужен исходный файл или точная причина из нового диалога.
