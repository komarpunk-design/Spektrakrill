Экспериментальный автономный пакет для попытки запуска через «Анализ данных» ChatGPT, без собственного сервера, OAuth и pip.

**В настоящей сессии ChatGPT пока не проверен.** Её правила могут запрещать нативное исполнение или не давать достаточно памяти/времени. Подтверждена работа в изолированном Linux, а не совместимость со всеми аккаунтами ChatGPT. Постоянное приложение в меню аккаунта не устанавливается; после сброса сессии архив может потребоваться загрузить снова.

Внутри: полностью статические Linux x86-64 executables, настоящий LibRaw + C++-движок Spektrafilm, исходные материалы и оригинальные PNG/TIFF-экспортёры Android-проекта. JPEG кодирует закреплённый libjpeg-turbo. Python 3.9+, только стандартная библиотека. Генерация фото не используется.

По умолчанию: Portra 400, Arctic, RMS, Layered Transport, Langmuir, Noritsu без бумаги. Размер — 1536 по длинной стороне; PNG/TIFF действительно 16 бит, JPEG — 8 бит. Есть warm и bw. Полное разрешение (--size 0) зависит от ресурсов.

Как попробовать: включить анализ данных, загрузить этот ZIP и камерный RAW, попросить обработать RAW приложением Spektrafilm из архива. Если RAW не принимается, прикрепить ZIP с одним RAW. Подробный запрос — CHATGPT-PROMPT-RU.md внутри пакета. Не нужно создавать VPS или подключать MCP.

Проверки: 6 unit-тестов; настоящие NEF и 26-МП RAF в чистом Python без numpy/Pillow/tifffile, сеть отключена, RAM 1 GiB, CPU 2, непривилегированный пользователь. Оба кадра обработаны, все экспорты проверены; SHA-256 каждого файла включён в manifest/receipt. ZIP и все manifest hashes проверены.

Исходники и инструкции находятся в коммите, указанном в manifest.json. Лицензии и уведомления компонентов сохранены. Оригиналы тестовых RAW и учётные данные в пакет не включены.
