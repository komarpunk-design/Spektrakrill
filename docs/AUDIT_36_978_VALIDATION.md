## Исправления жизненного цикла

- `scratch_pool_probe`: эксклюзивность параллельных lease, повторное использование, обнуление, move, лимит удержания, освобождение под давлением памяти при сохранённом GPU-reclaimer и контролируемый отказ при недостаточном бюджете.
- `parallel_limit_probe`: запрошенные ограничения 1/2/4/8 workers действительно ограничивают одновременно выполняющиеся тела; потерянной работы нет. При восстановлении температуры снимается только дополнительный лимит.
- `gpu_cancellation_probe`: реальные dispatch на Vulkan, отмена на 15 границах ожидания и сравнение следующего расчёта с эталоном после каждой отмены. Незавершённый GPU-пакет не оставляется без владельца ресурсов.
- `operator_report_probe`: отменённый/устаревший результат не заменяет последний принятый, история ограничена, параллельные обращения защищены.
- Mask/UI-тесты проверяют исходную арифметику масок, инвалидирование геометрии, существование сериализованных путей всех 128 native-параметров, переходы к контролам без переключения алгоритма, восстановление цели поиска и смену локали.

## Границы проверки

CPU CTest: 29/29. Vulkan-конфигурация: 33/33, из них семь требуют фактического dispatch. Vulkan-драйвер — программный Mesa Lavapipe. Проверки Adreno/Mali, тепловые замеры на телефоне и сравнение с измеренными аппаратными сканами здесь не проводились. Численная паритетность не доказывает аппаратную идентичность Nikon/Noritsu.

После сборки APK отдельно проверяются package/version, прежняя подпись, ZIP CRC, 16-KiB выравнивание APK и всех девяти native-библиотек. Полный скачанный файл сверяется с локальным по длине и SHA-256. Итоговые значения и число Android-тестов записываются в артефакт `Spektrafilm-9.78-qualification.json`.
