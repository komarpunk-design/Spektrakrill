# Нативная основа 9.57

## Что взято

Полный опубликованный исходный код `thetechgeekko/Spektrafilm-android`, tag `v1.0.0`,
commit `bb53c80ab81f6f1d885ff613f4218f83c6c87f65`, импортирован в `native-android/`.
Это самостоятельное нативное Android-приложение: исходный Compose UI, C++ движок,
LibRaw, обработка RAW, маски, кривые, библиотека, рецепты, рамки и экспорт автора.
WebView/Capacitor не участвуют в новом приложении. Исходники старого приложения сохранены.
Файловый манифест фиксирует неизменённые и адаптированные файлы донора, а не только сходство внешности.

## Рабочее пространство

Сохранена навигация автора: **Looks / Edit / Masks**, крупный просмотр, контекстные
панели. В Edit находятся Light, Color, Film, Print, Effects, Detail, Frame, Output, Lab.
Дополнительные регуляторы используют те же Dropdown, EnhancedSlider и SwitchRow,
включая числовой ввод, пояснения, индикацию изменений и сброс группы.
Локализации оригинала сохранены в исходниках; китайская исключена из сборки. Новые пояснения Lab — на русском. Основные тексты автора пока доступны на его языках, включая английский.

## Существенные границы

* Локальные сессии прежнего WebView не подхватываются новой библиотекой автоматически. Для переноса настроек предусмотрен импорт JSON-рецепта 9.56; исходные фотографии открываются повторно. Старые файлы и данные приложения не удаляются.
* Это новая нативная основа, а не обещание побитового совпадения с 9.56.
  Авторские RAW-конверсия, маски, GPU, цветокоррекция и рамки заменяют прежние оболочки.
* При активных дополнительных моделях Lab используется CPU и целый кадр:
  Prep/Auto Levels требуют общей статистики. Штатные настройки сохраняют GPU и обработку полосами.
* Рецепты 9.56 переносят общие параметры движка и Lab-модели; специфические настройки
  старых программных RAW-декодеров не воспроизводятся. Выбор исходника и файл экспорта
  не являются частью такого импорта. Импортированная рамка применяется кнопкой в Frame.
* Измеренные градации контрастной бумаги доступны только для исходной Multigrade;
  дополнительные печатные плёнки не получают выдуманных измеренных градаций.
* Изменение UI после отмены фонового расчёта защищено проверкой актуальности;
  выполняющийся единичный C++ расчёт может закончиться до освобождения ресурсов.
* Проверки на физическом Android-устройстве не проводились. Нативный UI нельзя
  проверить запуском прежнего браузерного предпросмотра.

Результаты фактических автоматических проверок и SHA-256 APK записаны в релизе.
