# Согласование предпросмотра и экспорта · 9.62

## Подтверждённые причины расхождения

1. Обычный установившийся fit-предпросмотр строил параметры с
   `skipGrainHalation = true`, хотя экспорт сохранял активные эффекты. Это
   отключало зерно и галяцию независимо от переключателей пользователя.
2. Нативный `spk_simulate_preview` принудительно включал сканерную и увеличительную
   LUT-интерполяцию. Экспорт уважал исходные значения параметров. Ошибка зависела
   от профиля и цвета; при одинаковом источнике расходились 14 из 32 первых тестов.
3. Preview очищал `gpu_export` и без проверки наличия GPU устанавливал внутренний
   GPU-флаг. При программном fallback мог выбираться другой генератор шума.
   Расширенная матрица обнаружила ещё 16 расхождений из 160 после исправления LUT.
4. Финальный grade читал изменяемое UI-состояние в фоне. Теперь CCTF, насыщенность,
   vibrance, gamut grade и локальные коррекции фиксируются вместе с параметрами
   того поколения, которое попало в кэш результата движка.

## Исправление

- Полный fit-предпросмотр получает все включённые параметры через
  `settledPreviewParams`. Кадрирование в редакторе кадра остаётся отключённым
  только для отображения редактируемых границ, сохраняя остальные эффекты.
- Только временный draft во время движения ползунка может пропускать зерно и
  галяцию. После паузы его заменяет полный расчёт.
- Нативный preview больше не подменяет выбранные LUT-настройки и не сбрасывает
  экспортный выбор генератора. Проверка GPU-доступности совпадает с экспортной.
- Изменён именно контракт preview; алгоритмы и сохранённые результаты полного
  экспорта не переделаны. UI и все режимы вывода сохранены.

Входной proxy и размер preview продолжают ограничиваться для интерактивной работы.
Полный fit-расчёт может занимать больше времени, поскольку теперь считает эффекты,
которые раньше пропускались. Размеры файлов, выбранный экспортный шарпинг, рамка,
JPEG-квантование и HDR-отображение не превращаются в свойства обычного fit-вида.
Экспорт Scene-linear по своему назначению сохраняет исходный линейный вход,
обходя плёночный результат.

## Фактическая проверка

- 1430 app unit/Robolectric тестов, включая сохранение эффектов в final-preview,
  кадрирование без отключения эффектов и неизменность grade-снимка после правок UI.
- Новый `preview_export_probe`: 160 побайтовых сравнений при одинаковом входе
  48×32 без уменьшения, четыре плёнки (Gold 200, Portra 400, HP5, Velvia),
  legacy/paper/digital/auto-levels/lab-scan, эффекты, LUT и GPU-request on/off.
  Результат: **0 расхождений**, только конечные RGB, параметры вызова не меняются.
- 20 ранее сохранённых экспортных RGB-буферов остались побайтово прежними.
- Прошли `output_probe` (35 реальных output-рендеров), `test_lut_cache_e2e`
  и `test_small_preview_aa` с исходными эталонами.
- `test_gpu_host` прошёл в host-сборке без GPU: проверена ветка fallback.
  Работа на физическом Vulkan-GPU этой средой не проверялась.
- Собран Android release APK; упаковка/JNI/публичное скачивание проверяются при выпуске.

Запуск новой проверки после сборки host-движка:

```sh
cmake --build /path/to/host-build --target preview_export_probe
/path/to/host-build/preview_export_probe native-android/engine/spektra-core/src/main/assets/spektra
```

Проверка равенства на одном входе не означает побайтового совпадения proxy-RAW
с полноразмерным RAW: интерактивный RAW использует уменьшенную демозаику, полный
экспорт — полную. Микрофактура, ресэмплинг и результаты внешних просмотрщиков не
проверялись по пользовательской паре файлов: конкретные примеры не предоставлены.
