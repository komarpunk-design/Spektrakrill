# 9.58 — расположение 9.56 в нативном UI

Изменения от 13 ноября 2026 (Москва). Основа UI и движка остаётся нативной версией 9.57,
импортированной из thetechgeekko/Spektrafilm-android v1.0.0. Меняется организация
рабочего пространства. React/Capacitor не возвращаются в новый APK.

Сохранены исходные Material 3 компоненты, темы, цветовые поверхности, инструменты,
числовой ввод, оптические регуляторы, просмотр, адаптивные панели, жесты,
кадрирование, маски, библиотека и окно экспорта. Код C++/JNI, профили и алгоритмы
обработки этим изменением не затрагиваются.

## Как устроен главный экран

Фотография остаётся в центре. На телефоне под ней находится исходная нативная
панель с двумя высотами и ручкой изменения высоты; внизу — семь разделов в порядке
9.56. На обычном экране 360 dp видны все семь; в окне уже 336 dp лента прокручивается,
чтобы сохранить сенсорные области не меньше 48 dp. В широком окне используются
исходные боковая панель и вертикальная навигация.

Над параметрами — вкладки инструментов выбранного раздела. Нажатие открывает
сразу все настройки инструмента. Дополнительного входа через заголовок карточки
Scan, списка Experimental или All settings нет. Вкладки закреплены, параметры
прокручиваются отдельно. При смене инструмента прокрутка начинается сверху.
Закрытие и повторное открытие раздела возвращает последний выбранный инструмент.

## Контрольная карта 9.56 → 9.58

| Раздел 9.56 | Порядок страниц в 9.58 |
|---|---|
| Камера | Экспозиция → Баланс белого → Подготовка → Оптика → Цветной фильтр → Входной цвет |
| Плёнка | Каталог → Формат → Спектр → Основа и маска → Профиль |
| Проявка | Push / Pull → Химия → DIR |
| Эффекты | Зерно → Галяция |
| Печать | Вывод → Бумага и печать → Основа бумаги → Пробная печать |
| Скан | Отделка скана → Настоящий негатив |
| Финиш | Кадрирование → Рамка → Цифровой тон → Цвет и размер → Файл |

Дополнения нативной основы сохранены:

* Камера: после основных страниц доступны «Очистка RAW» и «Исходник». Для обычной
  фотографии очистка RAW объясняет, какой исходник ей нужен.
* Эффекты: «Дата на плёнке» после зерна и галяции.
* Финиш → Цифровой тон: исходные кривые, насыщенность/вибрация,
  Highlights & shadows и Contrast mask. Эти независимые модели сохранены.
* Финиш → Файл: формат, качество JPEG, размер и имя; кнопка «Открыть сохранение»
  открывает исходное окно экспорта. Сохраняются его пресеты, метаданные,
  резкость экспорта, пакетная обработка и парные кадры.
* «Рецепты», «Маски», «Предпросмотр» доступны через исходное верхнее меню ⋮.
  В широком режиме они доступны также в меню боковой навигации.
* Библиотека, импорт фотографии, настройки приложения, сравнение, история,
  гистограмма и экспорт остаются на исходных местах в верхней панели.

## Где искать конкретные функции

* **Lab Scan:** Печать → Вывод → Получение изображения → Lab Scan · минилаб.
  Там же: фотобумага, Digital Reference, Auto Levels, негатив на просвет и
  исходный прямой спектральный скан плёнки без бумаги.
* **Layered Transport:** Эффекты → Галяция → Модель галяции.
* **RMS:** Эффекты → Зерно → Модель зерна.
* **Langmuir:** Проявка → DIR → Модель DIR.
* **Prep:** Камера → Подготовка. Экспозиция Prep отделена от экспозиции камеры.
* **Калибровка настоящего негатива:** Скан → Настоящий негатив.
* **Спектральные методы:** Плёнка → Спектр.
* **DX и рамки:** Финиш → Рамка.
* **Пробная печать:** Печать → Пробная печать.

Индикаторы изменений и сброс относятся к страницам. Например, сброс Подготовки
сохраняет экспозицию камеры, сброс Спектра сохраняет UV/IR-фильтры и размер вывода,
сброс Вывода сохраняет настройки резкости сканера. Выбранные маршруты объясняют
обход фотобумаги и съёмочных эффектов, не стирая сохранённые параметры.

## Совместимость и границы

Все 30 исходных нативных категорий имеют назначения в новой навигации. Имена Category,
схемы рецептов, значения параметров и C API не изменены. Дополнительные функции
нативной основы расширяют страницы 9.56, сохраняя их относительный порядок.

Это восстановление расположения, а не возврат старых алгоритмов и программных
RAW-декодеров веб-версии. Ограничения перехода с WebView остаются прежними:
локальные сессии 9.56 автоматически не переносятся; поддерживается импорт
JSON-рецептов. Сохранённые файлы пользователя не удаляются.

Проверка на физическом Android-устройстве не проводилась. Автоматизированные
Compose/Robolectric-проверки не являются пользовательским тестированием.
Фактические результаты тестов, подпись и SHA-256 приводятся в релизе 9.58.
