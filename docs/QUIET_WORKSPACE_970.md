# Компактная рабочая среда · 9.70

Задача: уменьшить количество одновременно показанных настроек без потери
инструментов, диапазонов, моделей обработки и точного числового ввода.
Алгоритмы и сериализация параметров остаются прежними.

## Решение

Рассмотрены три подхода:

| Подход | Плюсы | Проблемы |
|---|---|---|
| Длинная лента подвкладок с компактными слайдерами | Быстрое переключение знакомых инструментов | Функции за краем экрана; уменьшение контролов ухудшает работу пальцем |
| Последовательный мастер | Ясен первый запуск | Ограничивает свободное перемещение, неудобен для экспериментов |
| Существующие этапы + каталог инструментов + раскрытие групп | Понятные названия и назначение, поиск без знания этапа, обычные размеры контролов | Выбор инструмента внутри этапа требует открыть каталог |

Реализован третий вариант. Семь фотографических этапов сохранены. Длинная
лента подвкладок заменена одним компактным селектором текущего инструмента.
Рядом — поиск по всем инструментам, включая рецепты, маски и предпросмотр.
Поиск находит названия, назначение, параметры Lab и нативные пути параметров.
Русские запросы «норицу» и «норитсу» также находят Noritsu.

В каталоге видны назначение, фотографический этап и отметка «Изменено».
Можно ограничить каталог текущим разделом или изменёнными инструментами.
При вводе запроса поиск автоматически охватывает все разделы.
Фильтры переносятся на следующую строку на узких экранах.
Пустой результат объяснён; фильтры можно снять.

## Соответствие расположения

| Было | Стало |
|---|---|
| Камера: восемь горизонтальных подвкладок | Камера → селектор инструментов; все восемь инструментов сохранены |
| Плёнка: каталог, формат, спектр, основа, профиль в ленте | Плёнка → селектор с описаниями; общий каталог материалов сохранён |
| Проявка: Push/Pull, химия, DIR | Те же три инструмента; слои химии сразу видны, каналы и проявитель раскрываются отдельно |
| Эффекты: зерно, галяция, дата | Те же инструменты и модели; RMS показывает гранулярность сразу, остальные группы — по названию |
| Печать: вывод, бумага, основа, пробная печать | Те же инструменты; в большой панели бумаги одновременно открывается одна группа |
| Скан: скан без бумаги, настоящий негатив, спектральный скан | Те же три самостоятельных маршрута, доступные через селектор и общий поиск |
| Длинный список групп цифрового скана с независимым раскрытием | Подписанные строки; открыта одна группа за раз; яркость и режим всегда сверху |
| Noritsu: происхождение, хеши, файлы до рабочих регулировок | Рабочие переключатели выше; сведения, импорт и экспорт в «Данные профиля и файлы» |
| Финиш: кадрирование, рамка, тон, цвет/размер, файл | Все пять инструментов в селекторе; многосоставные панели раскрывают по одной группе |
| Рецепты, маски, предпросмотр в служебном меню | Меню сохранено; дополнительно доступны через общий каталог и поиск |
| Длинные пояснения постоянно между слайдерами | Краткий текст и кнопка информации; полный текст в прокручиваемом диалоге |
| Подробные подсказки переключателей прямо под названием | Кнопка информации рядом с переключателем; её нажатие не меняет эффект |

## Контроль сохранности

* Enum инструментов и фотографические этапы не сокращались.
* У каждого инструмента есть назначение; все инструменты перечисляются каталогом.
* Разбиение плотных Lab-групп использует исходные JSON-строки, не меняя метаданные,
  диапазоны, шаги, значения по умолчанию или привязки к движку.
* Проверяется, что каждый такой параметр представлен ровно один раз.
  Неизвестные будущие параметры попадают в «Другие параметры».
* Сворачивание только удаляет визуальное содержимое из композиции. Оно не
  сбрасывает, не обнуляет и не отключает соответствующий эффект.
* Изменения помечены в каталоге, в Lab-группах, группах скана и нативных разделах.
* Сбросы и точный ввод используют существующие обработчики.
* Открытая группа сохраняется через saveable-состояние панели.
* Первый клик по этапу по-прежнему открывает его первый/последний инструмент;
  повторный клик закрывает панель. Это не обязательный последовательный мастер.
* Встроенный профиль 9.69 и старые рецепты не мигрируют и не заменяются.

## Проверка UX

Экспертные сценарии и автоматизированные UI-проверки, не пользовательское исследование:

- Первый запуск: импорт и сохранение остаются в прежней верхней панели; каталог
  плёнок открывается прежним способом. Основной результат можно получить без
  раскрытия специализированных групп.
- Неизвестное расположение: кнопка поиска → запрос → инструмент. Например,
  «норитсу», «гамут», «калибровка», «перфорация» находят нужные инструменты.
- Последовательная настройка скана: переключение соседних групп не накапливает
  раскрытые блоки и сохраняет введённую чёрную точку 0.027.
- Эксперимент: переключение между RMS-группами сохраняет рецепт целиком.
- Возврат к работе: фильтр «Изменённые» показывает инструменты с изменениями;
  отметки остаются видимы и у свёрнутых групп.

На 320×640 проверяются поиск, доступ к профилю, файлам, регулировкам и точному
вводу. Компоновка реальной рабочей панели с предпросмотром проверяется через
EditorBody. Большие строки помощи прокручиваются. Проверки выполняются в
Robolectric, не на физическом Android-устройстве.

## Проверенные риски и исправления

1. Длинная лента скрывала инструменты справа — заменена каталогом с поиском.
2. Непонятно назначение инструмента — добавлена короткая подпись каждому.
3. Новичок не знает этап — поиск автоматически глобальный.
4. «Норицу» не находило английский Noritsu — добавлены русские варианты.
5. На узком экране обрезался фильтр изменений — фильтры теперь переносятся.
6. Можно раскрыть все группы скана — теперь группы взаимно сворачиваются.
7. Импорт/происхождение профиля вытесняли Film Sharp — перенесены в отдельную группу.
8. При загрузке встроенного профиля показывалось «нужен профиль» — добавлено состояние загрузки.
9. Пояснения вытесняли управление — полный текст открывается отдельно.
10. Нажатие на подсказку могло восприниматься как переключение эффекта — отдельная кнопка, проверена сохранность состояния.
11. Послойные поля RMS/химии перегружали панель — сгруппированы без изменения данных.
12. Потенциальная потеря будущих полей при группировке — добавлена резервная группа и проверка покрытия.

Остаётся проверить удобство с реальными пользователями и физическую клавиатуру/
TalkBack на устройстве. Поиск ведёт к инструменту, а не к конкретному слайдеру;
внутри него группа находится по явно указанным названиям параметров.

Дополнительная проверка всей панели выявила повтор заголовка и полноразмерную
строку сброса перед настройками. В телефонной панели повтор убран, сброс вынесен
в отдельную кнопку рядом с селектором инструмента. Действие и область сброса
сохранены; кнопка недоступна, если сбрасывать нечего.

Администрирование виртуального негатива больше не вытесняет выбор сканера с
первого экрана. Оно находится в группе «Виртуальный негатив и варианты» ниже
рабочих регулировок. Создание, фиксация, варианты, переименование, удаление и
управление сохранением доступны там же; вложенная внешняя карточка убрана.
В режиме просмотра самого негатива группа остаётся в его рабочей панели.
