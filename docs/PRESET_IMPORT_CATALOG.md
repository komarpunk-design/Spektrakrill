# Импорт JSON и каталог рецептов · 9.59

В нативном редакторе откройте «Рецепты». Разделы фотографического процесса и
движок обработки сохранены. Каталог использует Compose и текущую тему приложения.

## Что изменено

Раньше импорт пытался сразу применить единственный JSON к фотографии, не добавлял
его в сохранённые рецепты и скрывал причину ошибок чтения. Теперь файл сначала
читается, проверяется целиком и сохраняется в «Мои». Для применения нужно нажать
карточку или «Применить». При импорте текущая фотография не изменяется.

Поддержаны:

- Собственный Android JSON схемы `org.spektrafilm.preset`, версии 1–2.
- Рецепты прежней версии Lab 9.56 с `filmStock`, в том числе без блока `experimental`.
- Обёртка `params`, массив рецептов, наборы `presets` и `looks`.
- Авторский формат Spektrafilm (`io`, `settings`, `filmRender`, `printRender`)
  и соответствующие имена Python GUI со знаком подчёркивания.
- UTF-8 BOM и скопированные блоки JSON с Markdown-ограждением.

Проверяется тип и допустимость известных значений; будущая версия схемы и
профиль плёнки вместо рецепта дают понятную ошибку. Не все поля внешних программ
имеют соответствие в Android: для неизвестных полей показывается предупреждение,
а исходный объект сохраняется в `sourcePreset` внутри JSON рецепта. Предупреждение
видно и в карточке. Это не означает, что неизвестный алгоритм был применён.

Ограничение документа — 4 МиБ, набора — 128 рецептов. Весь набор проверяется до
записи. При ошибке записи убираются только файлы этого импорта. Существующие
рецепты не перезаписываются: повтор имени получает суффикс ` - 2`, ` - 3` и т. д.
Русские имена сохраняются; разделители путей и неподходящие символы заменяются.

## Как устроен каталог

- Сверху: импорт JSON через Android Documents и сохранение текущей обработки.
- Поиск по названию, описанию, плёнке и фотобумаге.
- Фильтры «Все / Избранное / Встроенные / Мои»; на узком экране строки переносятся.
- Карточки с названием, материалами, маршрутом вывода и предупреждениями.
- Звезда добавляет рецепт в избранное; выбор сохраняется между запусками.
- Меню своей карточки экспортирует именно этот рецепт или удаляет его с
  подтверждением и предложением отмены.
- Сохранение и вставка JSON текстом открываются прямо в панели. Замена ранее
  сохранённого рецепта требует подтверждения.
- После импорта открывается «Мои» и очищается поисковая строка.
- Рецепт с отсутствующей плёнкой/бумагой сообщает, какой профиль нужно установить;
  применение становится доступно после импорта материала в каталог плёнок.
- Сила пресета, встроенный предпросмотр на фотографии, копирование настроек,
  версии, применение предыдущей обработки и все прежние варианты LUT сохранены.
  Дополнительные операции раскрываются кнопкой «Копирование, версии и LUT».

Каталог — ленивый список в ограниченной по высоте панели, с закреплённым поиском
и фильтрами. Высота панели регулируется отдельно от панелей остальных инструментов.
Применение рецепта сохраняет кадрирование текущей фотографии; чтение файла идёт
в фоне с защитой от запоздалого применения после переключения фотографии.

## Проверка и границы

Добавлены проверки реального экспорта Lab 9.56, старого заводского набора из
27 рецептов, Android JSON, Python GUI, BOM, массивов, неизвестных полей, дубликатов,
ошибок записи и сохранения кадрирования. Robolectric проверяет импорт через
ActivityResult/SAF и настоящий FilePresetRepository, ошибки чтения, поиск,
избранное, экспорт выбранной карточки, подтверждение замены и размеры каталога
в настоящем EditorBody. Снимок интерфейса получен Robolectric Native Graphics.

Полный результат тестов и сборки указан в release notes 9.59. На физическом Android
проверка в этой среде не проводилась. Конкретный файл, с которым пользователь
столкнулся с ошибкой, не предоставлен; проверены перечисленные форматы и фикстуры.
C++/JNI-алгоритмы и числовые значения встроенных пресетов в этой версии не изменены.
