Экспериментальный APK с оригинальным desktop darktable 5.6.2 (ARM64).

Включены неизменённые GTK-интерфейс, движок, данные и все шесть штатных рабочих представлений. Это локальная Linux/glibc-среда через PRoot и Broadway внутри одного APK, не нативный Android/Bionic-порт. Termux и удалённый сервер не нужны. Прежнее мобильное приложение остаётся отдельно.

Проверены настоящий Nikon NEF и JPEG → PNG, неизменность 1705 оригинальных файлов, зависимости 546 ELF, полный архив runtime, 7 тестов оболочки в Debug/Release, сборка, lint (0 ошибок), подпись APK и контрольные суммы. Полный графический сценарий на ARM64 и запуск на Android-устройстве пока не квалифицированы. Работа GPU, USB-камер, принтеров, MIDI и системного цветового управления Android не подтверждена. Это ещё не полный проверенный перенос всех возможностей desktop на Android.

Требуется Android 8+ ARM64 и минимум 2 ГБ свободного места, плюс фотографии и кэш. APK около 356 МиБ, development-подпись, target API 28 необходим для запуска Linux ELF. Подробности и ограничения — PORT-STATUS.md.

Импорт Android копирует исходники в /photos; затем откройте их штатным импортом darktable. Экспортируйте в /exports и сохраните результат кнопкой «Экспорт» в Android. Каталог версии development 5.8 и маски v7 автоматически не переносятся в stable 5.6.2.

Исходники новой Android-оболочки — отдельный файл -source.zip. Также приложены исходники оригинального darktable и PRoot. APK хранится в Git LFS; существующие ветки и прежние релизы не перезаписываются.
