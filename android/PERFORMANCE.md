# Предпросмотр и отклик — alpha 3

Подтверждённые причины лишней нагрузки alpha 2:

- Каждый шаг обработки использовал desktop-предел предпросмотра 12 MP. Android не передавал экранный масштаб.
- Render записывал RGBA, который Android не читал, затем Save кодировал PNG, который и показывался.
- Save повторно извлекал метаданные исходника даже с copy_metadata=false.
- Открытие раздела заранее создавало контролы всех закрытых групп.
- Каждая правка немедленно ставила запись session/sidecar в ту же очередь перед рендером.

Исправления:

- Отдельные Android-команды android_preview/android_original: экранный масштаб, по умолчанию длинная сторона 1280 px, варианты 768/2048. Декодированный исходник остаётся полным, его кеш используется повторно. RAW не подменяется встроенным JPEG.
- Размер включён в ключ кеша; запрос полного экспорта всегда идёт исходным Render без экранного ограничения, с отдельной полной геометрией.
- Промежуточный ненужный RGBA для обработанного предпросмотра больше не записывается. PNG остаётся общим путём показа crop/Post/borders через тот же Save.
- Без запроса копирования метаданных исходник ради EXIF больше не читается.
- Закрытые группы и дерево полной схемы строятся при раскрытии; раскрытие сохраняется при редактировании.
- Запись рецепта объединяется после паузы 1 с; onStop сохраняет сразу. История действий остаётся отдельной для каждого изменения. Устаревшие запросы предпросмотра по-прежнему пропускаются.
- Статус показывает фактические размеры обработанного прокси, backend и время Render+Save.

Проверка использует FFI, полный исходник 1536×1024 и прокси 512×341. В первом замере host CPU debug: полный кадр 18420 мс, прокси 2088 мс. Это Linux debug, ограниченные потоки, синтетический кадр и другой размер, чем Android default; числа не являются прогнозом скорости на телефоне. Проверено, что исходник декодирован один раз, ненужный RGBA не создан, оригинал показан в экранном размере, а PNG полного экспорта до и после прокси совпадает побайтно. Первое чтение RAW, холодная калибровка материала и тяжёлый Reference-export этим не отменяются.

Новые проверки дополняют исходный набор: 30 native tests, 18 Android/Robolectric API 26/35; lint без ошибок. Физическое Android-устройство недоступно, реальная скорость Vulkan/CPU и время открытия конкретного RAW требуют проверки на нём.
