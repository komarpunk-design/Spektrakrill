# Negs for Android — native port (alpha 3)

Отдельное Android-приложение на исходном Rust-движке **negs 0.18.0**, upstream `8154a6a`. Package: `app.negs.android`; Android 8+; ARM64. Spektrafilm Lab устанавливается и хранит данные отдельно.

Это нативный Android-клиент через JNI, без WebView, сервера и загрузки фотографий в сеть. Android-манифест не запрашивает доступ к интернету. Изображения выбираются через системный Storage Access Framework и копируются в приватную библиотеку приложения. Удаление приложения удаляет эти копии и внутренние рецепты; оригиналы в выбранной папке приложение не изменяет. Экспорт и `.negs` можно сохранить в выбранное пользователем место.

## Что перенесено

| Возможность исходного negs | Android |
|---|---|
| Каталог всех плёнок и бумаг | Данные и каталог исходного движка; поиск по названию |
| Спектральная обработка, зерно, галяция, DIR, кривые, базы, диффузия, подготовка и Post | Исходный Rust-код; основные разделы и полная схема параметров |
| Hanatos / Arctic / Mallett, управление цветом и гамутом | Исходные модели и данные |
| GPU Fast / CPU fallback | wgpu Vulkan; CPU при отсутствии подходящего backend |
| Reference | Отдельная библиотека f64, принудительно CPU, прямой спектральный расчёт без enlarger/scanner LUT; память освобождается после экспорта |
| RAW / JPEG / PNG / TIFF | Исходные rawler + vendored LibRaw; ICC и EXIF обрабатывает исходный IO |
| Пресеты | Импорт и экспорт через оригинальные preset handlers, совместимость с поддерживаемыми ими JSON |
| Скан настоящего негатива | Отдельный маршрут; определение базы, Auto Print, замер экспозиции, нейтральная точка, калибровка и flat-field параметры |
| Match camera brightness | Исходные brightness_reference / place_exposure, по кнопке после загрузки |
| Оригинал / зум / история | Сравнение с исходником, pinch/pan, undo/redo, восстановление сеанса |
| Кадрирование / горизонт / поворот / отражение | Точная геометрия и рамки сохраняются исходным Save; свободный прямоугольник выбирается на исходнике |
| Рамки | Solid / film 120 / keyline / 35mm с оригинальными текстурами и edge print |
| Экспорт | Полноразмерный пересчёт; JPEG 8 бит с качеством, PNG/TIFF 8/16 бит, ICC и EXIF, выбранное выходное пространство |
| LUT | Оригинальный экспорт 33³ `.cube`; пространственные эффекты туда не входят |
| Библиотека | Несколько файлов, импорт папки, отдельные рецепты фотографий, копирование/вставка, дубликаты |
| `.negs`, рейтинги, флаги | Исходный crate negs-library; атомарная запись и защита новых/повреждённых файлов; импорт/экспорт sidecar |
| Пакет | Текущий рецепт применяется ко всем открытым фотографиям; последовательный полноразмерный экспорт в выбранную папку |

Интерфейс перенесён на Android Views: фотография, горизонтальная навигация и панель с изменяемой высотой. Названия, диапазоны, шаги, варианты и подсказки контролов генерируются из `web/controls.js`; значения по умолчанию берутся из каталога движка. Точный ввод не ограничен разрядностью слайдера. В «Все параметры» доступна полная текущая схема, включая специализированные параметры. `null` сохраняет профильное значение материала.

## Границы этой сборки

Это первая alpha, а не заявление о полном паритете всех desktop-сценариев. Пока не перенесены полноценный contact sheet с превью материалов, RAW+JPEG pairing, весь UI отбора/фильтрации и darkroom rolls исходной desktop-библиотеки, автоматическое наблюдение за внешней папкой. Match brightness запускается вручную и автоматически не пересчитывается при смене плёнки. Некоторые технические подписи и подсказки остаются английскими. Apple RAW/Metal не являются Android API: используются LibRaw/rawler/Vulkan.

Физический Android и его GPU в этой среде недоступны. Тесты host/Robolectric не доказывают работоспособность на всех драйверах. Полноразмерная спектральная обработка, особенно Reference больших RAW, требует значительной памяти. Alpha APK подписан публичным development-ключом, а не production-ключом магазина.

## Сборка из исходников

Нужны Rust 1.89+ с `aarch64-linux-android`, Node.js, JDK 21, Android SDK 37 / build-tools 36.0.0 / NDK 28.2.13676358. Gradle Wrapper включён.

```sh
rustup target add aarch64-linux-android
export ANDROID_HOME=/path/to/android-sdk
bash android/build.sh
```

Скрипт копирует исходные data-файлы и лицензии, генерирует контролы/версию assets, собирает Fast и Reference, затем APK. Каталоги сборки и сгенерированные копии данных исключены из Git. Путь результата: `android/app/build/outputs/apk/release/app-release.apk`.

```sh
android/gradlew -p android :app:testDebugUnitTest :app:lintRelease
```

Для уже скачанных test SDK можно передать `-ProbolectricSdkDir=/path/to/android-all-jars`.

Лицензия GPL-3.0-only и исходные атрибуции сохранены. LibRaw: LGPL/CDDL, его лицензии также включены в APK.

## Быстродействие alpha 3

Экранный предпросмотр по умолчанию ограничен длинной стороной 1280 px; в меню ⋮ → «Качество предпросмотра» доступны также 768 и 2048 px. Это не ограничивает полноразмерный экспорт. Первый RAW декодируется по-прежнему из сенсорных данных, затем используется кеш исходника. См. [PERFORMANCE.md](PERFORMANCE.md).
